# Flutter 应用 — 手动测试清单

🌐 [English](manual_test_checklist.md) | 中文

将此文件粘贴到 **GitHub Issue** 中即可获得可点击的复选框（`- [ ]` / `- [x]`）。在仓库中查看文件仅渲染复选框；切换状态需编辑文件或使用 Issue/PR。

**前置条件：** iOS 和/或 Android 设备或模拟器 · 通过 `API_ENV` / `API_HOST` 配置的已知 API · 至少两个账户（作者 A、导入者 B）。

---

## 0. 设置与冒烟测试

- [ ] `flutter doctor` 足以正常运行
- [ ] 应用可启动（`flutter run` 和/或 release 构建）
- [ ] 冷启动显示登录页（若已登录则恢复会话）
- [ ] 首帧无崩溃
- [ ] 应用连接到预期的 API 环境（`debug` / `dev` / `release`）

---

## 1. 认证

### 登录（`/login`）

- [ ] 有效凭据 → 成功，进入卡组标签页
- [ ] 错误密码 → 显示服务器消息（如“凭据无效”），停留在登录页
- [ ] 空字段 → 校验 / 阻止提交
- [ ] 加载状态禁用控件；无重复提交
- [ ] 密码可见性切换正常（如存在）
- [ ] 工具栏主题切换在登录页正常
- [ ] 工具栏语言切换（EN / 中 / 日）立即更新文案
- [ ] 注册链接打开注册页
- [ ] 忘记密码打开忘记密码流程

### 注册（`/register`）

- [ ] 正常路径：邮箱、用户名、密码、确认密码 → 成功
- [ ] 空字段 → 提示填写所有字段
- [ ] 密码不一致 → 报错
- [ ] 用户名/邮箱重复 → 可读的 API 错误
- [ ] 返回登录正常

### 忘记 / 重置密码

- [ ] 忘记密码：提交邮箱 → 确认提示（“若账户存在…”）
- [ ] 打开带 `?token=` 的重置链接 → 设置新密码 → 可登录
- [ ] 缺失/无效 token → 明确报错
- [ ] 重置后，旧密码失效；新密码可用

### 验证邮箱（`/verify-email?token=`）

- [ ] 有效 token → 成功
- [ ] 缺失 token → 缺失 token 报错
- [ ] 无效/过期 token → 报错 + 返回登录路径

### 会话 / 认证门禁

- [ ] 已登录用户打开 `/login` 重定向到主界面
- [ ] 未登录用户无法打开 `/study`（重定向到登录）
- [ ] 登录状态下杀掉应用 → 会话恢复
- [ ] 退出登录 → token 清除；卡组/个人资料显示锁定占位
- [ ] JWT 过期 → 会话过期提示 / 强制重新登录（如可复现）

## 2. 主导航（标签页）

标签页：**卡组** | **发现** | **个人资料**

- [ ] 标签页切换正常；列表滚动位置按预期保留
- [ ] 访客 / 未登录：发现仍可访问
- [ ] 访客：卡组与个人资料显示锁定 + 登录 CTA → 登录
- [ ] 从占位登录后，预期标签页内容出现
- [ ] 发现详情可在未认证状态下打开（浏览）
- [ ] 从学习 / 发现详情返回路径合理

## 3. 个人资料

- [ ] 加载用户头部（用户名 / 邮箱）
- [ ] 先加载后显示内容；错误状态 + 重试正常
- [ ] 切换语言：English / 日本語 / 简体中文 — 全应用文案更新
- [ ] 切换主题：浅色 / 深色 / 米黄 / 跟随系统 — 立即生效
- [ ] 主题在应用重启后保持
- [ ] 标签行打开标签页
- [ ] 退出登录：取消保持会话；确认退出登录
- [ ] 底部显示应用版本号

---

## 4. 标签（个人资料 → 标签）

- [ ] 空状态 + 创建第一个标签
- [ ] 创建标签（名称必填，描述可选）
- [ ] 重复名称 → 报错
- [ ] 编辑标签名称/描述
- [ ] 删除标签 → 从列表移除
- [ ] 搜索按名称/描述过滤
- [ ] 打开标签 → 带标签的事实条目列表
- [ ] 卡组/事实条目编辑器中的标签选择器：搜索、多选、内联创建、完成

## 5. 卡组列表

- [ ] 空状态：暂无卡组
- [ ] 下拉刷新重新加载
- [ ] 加载更多 / 分页在大量卡组时正常
- [ ] API 失败时显示错误 + 重试
- [ ] FAB 打开创建卡组
- [ ] 可拖动 FAB 位置保持（`fab_decks`）
- [ ] 卡组卡片正确显示名称和统计（到期 / 新卡 / 进度）
- [ ] 点击卡组 → 进入该卡组的学习页
- [ ] 已发布来源：发布/更新控件 + 存在未发布更改时显示徽标
- [ ] 导入卡组：检查更新控件 + 有可用更新时显示徽标
- [ ] 发布/同步后徽标清除
- [ ] 应用后台 → 前台：分享状态轮询恢复

## 6. 创建 / 编辑 / 删除卡组

### 创建

- [ ] 名称必填
- [ ] 至少需要两个列标题；空标题被阻止
- [ ] 添加 / 删除 / 排序字段
- [ ] 每日卡片数选择器更新间隔提示
- [ ] 创建时附加卡组标签
- [ ] 保存 → 卡组出现在列表中；打开学习正常

### 编辑（卡组菜单 → 编辑卡组）

- [ ] 重命名卡组 → AppBar 标题更新
- [ ] 更改速率
- [ ] 添加 / 重命名 / 排序 / 删除字段（来源卡组）
- [ ] 导入卡组的编辑限制生效
- [ ] 卡组标签添加/移除
- [ ] 不保存离开 → 卡组不变

### 删除

- [ ] 确认取消 → 未删除
- [ ] 确认删除 → 退出学习，从列表移除
- [ ] 已发布来源 → 无法删除；显示错误提示

## 7. 学习会话（SRS）

- [ ] 加载 → 第一张到期/紧急卡片
- [ ] 空卡组：无卡片提示
- [ ] 全部完成：提示 + 再次复习
- [ ] 翻面前仅显示正面
- [ ] 翻转 / 显示答案 → 显示背面
- [ ] 间隔滑块（困难 ↔ 简单）在滑块上显示间隔标签
- [ ] 提交间隔 → 下一张卡片；今日到期进度推进
- [ ] 会话进度不会在会话中途错误重置
- [ ] 隐藏卡片 → 跳过；不作为下一张紧急卡片返回
- [ ] 删除卡片 → 确认文案正确；仅删除该卡片；事实条目/其他卡片保留
- [ ] 标签过滤：按卡组标签过滤 → 仅显示匹配卡片；清除过滤
- [ ] 标签过滤为空 → 无匹配卡片提示 + 清除过滤
- [ ] API 错误 → 提示；可恢复
- [ ] 返回卡组；列表统计合理刷新

## 8. 卡片内容与字体

### 文本与注音

- [ ] 纯文本正确渲染
- [ ] Wiki 注音 `[[漢字|かんじ]]` 在基础文本上方显示读音
- [ ] 混合注音 + 纯文本换行正常
- [ ] 无效/部分标记按字面文本显示（不崩溃）

### 卡片媒体

- [ ] 音频播放 / 暂停 / 停止；跨卡片无卡住重叠
- [ ] 图片加载；加载失败显示加载失败状态
- [ ] 视频播放；全屏进入/退出；控件可用
- [ ] 单面多个媒体；小屏幕可滚动
- [ ] 短视口 / 键盘打开：卡片 + 控件仍可用

### 字体面板（卡组菜单 → 字体）

- [ ] 正面 / 背面标签页
- [ ] 排版控件实时更新预览
- [ ] 设置按卡组持久化并应用于学习卡片

---

## 9. 添加 / 编辑事实条目

### 添加事实条目（卡组菜单）

- [ ] 行与卡组字段匹配；允许处添加/删除行
- [ ] 仅文本保存创建事实条目 + 卡片
- [ ] 事实条目可选标签
- [ ] 附加图片（文件 + 相册）
- [ ] 附加视频
- [ ] 附加 / 录制音频（麦克风允许 + 拒绝）
- [ ] 长按清除附件
- [ ] 空事实条目被阻止并显示明确提示
- [ ] 保存后，新卡片出现在学习中（或再次复习 / 重新加载后）
- [ ] 导入卡组：添加走覆盖 / 发件箱路径（非直接作者写入）

### 编辑事实条目（卡片菜单）

- [ ] 编辑文本 / 媒体 / 标签；保存后重新加载当前卡片
- [ ] 注音标记在编辑/显示后保留
- [ ] 来源卡组：直接保存
- [ ] 导入卡组：覆盖 + 提交/暂存给作者
- [ ] 取消丢弃未保存更改

## 10. 发现

### 列表

- [ ] 最新过滤加载公开卡组
- [ ] 收藏过滤：空状态和已填充状态
- [ ] 按名称 / 作者 / 标签搜索
- [ ] 下拉刷新
- [ ] 错误 + 重试
- [ ] 卡片显示事实条目数、所有者、相对时间、已导入/不可用徽标

### 详情（`/discovery/:id`）

- [ ] 加载字段、描述、事实条目数
- [ ] 收藏 / 取消收藏（心形）
- [ ] 访客：导入提示登录
- [ ] 已登录：导入 → 成功提示 → 卡组列表刷新
- [ ] 去学习打开导入的卡组
- [ ] 无法导入自己的卡组 → 提示
- [ ] 重复导入 → 提示
- [ ] 不可用 / 未找到 → 错误 UI + 重试
- [ ] 作者重新发布后，导入者看到更新徽标（跨账户）

## 11. 发布（仅来源卡组）

- [ ] 首次发布 → 卡组出现在发现中
- [ ] 有更改时重新发布 → 按设计显示版本 / 更新预览
- [ ] 无更改时重新发布 → 无更改报错（或等效提示）
- [ ] 发布刷新发现
- [ ] 未发布更改的列表徽标在发布后清除

## 12. 导入协作

### 导入者（导入卡组）

- [ ] 卡组菜单显示待处理发件箱 + 检查更新（无发布 / 贡献收件箱）
- [ ] 编辑事实条目 / 添加事实条目 / 标签更改创建待处理项
- [ ] 发件箱：待处理 vs 已发送标签页
- [ ] 全选 / 发送所选 / 忽略 / 清除
- [ ] 部分发送失败提示
- [ ] 报告问题（音频 / 内容 / 其他）；其他需填写详情
- [ ] 检查更新：摘要；展开详情；接受/保留决策；同步
- [ ] 同步后，学习与决策一致；列表徽标清除

### 作者（已发布来源）

- [ ] 卡组菜单：贡献收件箱
- [ ] 列出未处理贡献；加载更多
- [ ] 预览前后文本与音频
- [ ] 接受 / 忽略 / 解决
- [ ] 接受的更改应用到来源；重新发布对导入者可见

- [ ] 提示不会无限期阻塞 UI

- [ ] 破坏性对话框需确认

- [ ] 冒烟测试 浅色 / 深色 / 米黄 / 跟随系统 × EN / JA / ZH 在登录、卡组、学习、发现、个人资料

## 15. 端到端场景

- [ ] **作者生命周期：** 注册 → 创建卡组 → 添加事实条目（文本 + 音频 + 图片 + 注音）→ 学习复习 → 发布 → 编辑事实条目 → 重新发布
- [ ] **导入者生命周期：** 发现 → 收藏 → 导入 → 学习 → 编辑/报告 → 发送贡献 → 作者接受 → 导入者检查更新并同步
- [ ] **认证恢复：** 忘记密码 → 重置 → 登录；验证邮箱链接；退出/登录；会话恢复
- [ ] **标签：** 创建标签 → 附加到卡组与事实条目 → 按标签过滤学习 → 从个人资料管理
- [ ] **空 / 边界：** 空卡组、全部完成、隐藏卡片、删除最后一张卡片、删除卡组

---

## 16. QA 模式（导入卡组，`docs/qa-mode.md`）

- [ ] 仅导入卡组的卡组菜单显示 **QA 模式**
- [ ] 已由人工核验的列默认勾选；无文本/音频的列不可勾选
- [ ] **已核验** 确认弹层列出勾选的字段名与 PUT JSON；发送后质量已保存
- [ ] 质量接口故障只在 QA 模式内提示 —— 学习、编辑与同步照常可用
- [ ] 列 **编辑** → 保存后立即发送 `fact_edit` 贡献（未发送列表不留残留）
